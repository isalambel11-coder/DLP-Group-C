# Data Flow

1. **Sources:** user activity, endpoint/network metadata and DLP-related events.
2. **Preparation:** validation, cleaning, encoding and missing-value handling.
3. **Features:** behavioural/contextual features are generated.
4. **Detection:** baseline ML/anomaly model produces a prediction or anomaly score.
5. **Decision:** suspicious events are assigned a risk/alert status.
6. **Output:** results are logged for later evaluation.
