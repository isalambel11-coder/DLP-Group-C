# Expected Output Table

| Output | Purpose |
|---|---|
| Detection results | Identify normal and suspicious activities |
| Confusion matrix | Examine classification errors |
| Precision | Measure correctness of positive detections |
| Recall | Measure how many relevant threats are detected |
| F1-score | Balance precision and recall |
| Graphs/tables | Present and compare findings |
| Performance/latency | Assess practical feasibility where applicable |
